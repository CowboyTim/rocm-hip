# Commit: Mandelbrot Fractal Renderer via HIP on AMD Strix Halo UMA

## Changes
- **kernels.hip**: Replaced simple increment kernel with Mandelbrot fractal renderer using thread-per-pixel compute (0–4096 escape iterations + smooth normalized coloring)
- **main.cpp**: Rewrite to render 800×600 Mandelbrot set over unified memory — zero `memcpy`, GPU operates directly on mmap'ed `/dev/shm` file region registered with `hipHostRegisterMapped`. Includes verification of known Mandelbrot geometry (cardioid, needle, seahorse valley). Outputs valid PPM image.
- **Makefile**: Fixed kernel compilation (compile `.co` separately but don't pass to linker; link only `main.o`), target renamed to `mandelbrot`, simplified build rules.

## Architecture
- ROCm: `/opt/rocm` (gfx1151)
- UMA trick: CPU and GPU share physical pages — after `hipHostRegisterMapped`, no copying needed, kernel writes directly into host-visible buffer
